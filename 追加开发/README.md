## 中文：使用顺序

1. 先确认 Source 源头、本番设计书、テーマID／名称、追加对应一览和参考 テーマ，再建立本次资料索引。
2. 调查 Source 漏项、用途、历史改修 Diff、设计要求及数据库 Object×环境范围，形成可使用的开发 Input。
3. 根据正式要求与确认后的 Input 开展设计、开发、单体测试、连接测试和交接；已准备好的项目可独立推进。

任务票中的 **ADD** 是追加开发主流程，**SUP** 按实际需要使用，**LATER** 是后续调查。AI 智能体与 Manual 调查放在[通用提示词](../通用提示词/README.md)，作为后续工作使用。

14 项目核对提示词本轮负责调查、记录补充建议和保存 Input；正式对应一览的更新按后续任务执行。任务正文有完整中日两版，选择一种语言执行一次。资料发布不表示公司调查、开发或测试已经完成。

## 日本語：使用順

1. Sourceの出所、本番設計書、テーマID・名称、追加対応一覧、参考テーマを確認し、本次の資料索引を作ります。
2. Source漏れ・用途・過去の改修Diff・設計要求・DB Object×環境の範囲を調べ、利用できる開発Inputにまとめます。
3. 正式要求と確認済みInputに従い、設計・開発・単体試験・結合試験・引継ぎへ進みます。準備済みの案件は個別に進められます。

タスク票の **ADD** は追加開発の主工程、**SUP** は必要時の支援、**LATER** は後続調査です。AIエージェントとManual調査は[通用提示词](../通用提示词/README.md)にあり、後続作業として使います。
