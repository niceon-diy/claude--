整理日期：2026-11-11（日本时间）。本包用于实际实施，替代此前“只做需求分析、回答后等待确认”的任务阶段。

**直接使用：[中文版完整提示词](P003_外层Agent编排与设计开发测试全流程执行提示词.md)。**

2026-11-12 按语言分目录保存。本目录仅放中文版的完整提示词、使用说明、问答模板和核对表。两种语言是同一任务的两个完整版本，**选择一种语言执行一次即可**，避免重复部署、DDL、数据导入或测试。

本次要求是：自己的设计、开发、测试外层 Agent，先处理输入，再调用现有 Framework Agent，检查真实输出，有依据地补充或返工。测试尽量沿用原有能力，接通 Matrix／固定 Case／想定 → 数据准备 → 程序和 Oracle 整备 → 执行 → 取结果 → 比较。问题集中写文件，其他工作连续推进。

## 最省事的使用方法

1. 在公司电脑取得本包，打开实际业务工程中的 Claude。
2. 将下方启动指令中的路径替换为公司副本里 P003 的实际绝对路径，发送一次。
3. 如果 Claude 无法读取本包文件，就直接复制 P003 中从“提示词开始”到“提示词结束”的全文发送。

```text
请读取并执行这个文件中的完整任务正文：
【公司电脑上 P003_外层Agent编排与设计开发测试全流程执行提示词.md 的绝对路径】

这是实际实施任务，不是只做需求分析。以当前公司实际业务工程为对象：
实现我的设计、开发、测试外层 Agent，优先调用现有 Framework 的 Agent 和工具，
完成输入处理、输出检查、有依据的补充及定向返工。
测试以我的 Matrix、固定 Case 和想定为基准，接通个人开发环境中的
程序部署、Oracle 结构更新、初期表和测试数据、运行、采集与比较。
能自行查到的信息先自行查；必要问题集中写到公司目录内的一份问答文件，
只阻塞相关步骤，继续完成所有不依赖回答的工作，不逐阶段等待我确认。
请按文件给出的权限、版本、验证和交接规则，从实际状态开始持续执行。
```

不必先填完全部路径、账户或八项问题。Claude 先读当前工程和有效配置；确实缺资料时写文件。账号密码不放在提示词、问答或公开 Git 中。
