# 会话交接标准提示词／会話引継ぎ標準プロンプト

## 中文

### ① 旧会话：生成交接记录

请根据本会话的实际工作生成交接记录，让另一个没有本会话历史的AI能够继续任务。

交接记录必须包含：
1. 任务目标、调查范围、限制条件和验收标准。
2. 已读取的资料及其准确位置；未读取的资料单独标明。
3. 已完成事项、已确认结论及对应证据。证据注明文件路径或URL、章节或行号，以及可核实的版本或日期。
4. 未完成事项、疑点、阻塞原因和需要用户确认的问题。
5. 用户已确认的决定与尚未确认的建议，明确区分。
6. 下一步具体操作，以及执行前必须读取的资料。

要求：
- 区分事实、推测和未确认事项，不把计划写成已完成。
- 结论注明适用范围和限制，不因局部检查而声称全量无遗漏。
- 引用已有成果的准确位置，保留关键判断依据，避免只写笼统摘要。
- 仅整理记录，不执行新的调查，不修改业务代码。
- 优先遵守项目已有的交接存储规则；没有明确规则时，先在回复中输出Markdown正文，不擅自创建文件。

### ② 新会话：读取并继续

请接手以下任务，先读取交接记录：
【交接记录路径，或在此粘贴正文】

请按以下顺序执行：
1. 读取交接记录及其中指定的必要资料；无法访问、缺失或版本不明的内容明确列出，不假装已读。
2. 简要复述任务目标、限制、已完成事项、未完成事项及下一步，检查是否存在矛盾。
3. 将交接记录视为工作线索；引用已有结论时检查证据是否支持、版本是否适用，关键结论回查原始资料。
4. 在已有授权范围内继续下一项未完成工作；信息不足时，只暂停受影响的部分并说明需要补充什么。
5. 按项目规则更新进度、结论、证据和待办，使后续会话能够继续接手。

不要重复已确认且证据仍适用的工作，不扩大任务范围，不擅自修改业务代码。每次汇报只讲一个重点，并明确实际完成了什么、还剩什么。

## 日本語

### ① 旧会話：引継ぎ記録の作成

この会話で実際に行った作業に基づき、この会話の履歴を持たない別のAIがタスクを継続できる引継ぎ記録を作成してください。

引継ぎ記録には、必ず以下を含めてください。
1. タスクの目的、調査範囲、制約条件、受入基準。
2. 読み取った資料と正確な所在。未読資料は別に明示すること。
3. 完了事項、確認済みの結論、対応する証拠。証拠にはファイルパスまたはURL、章・節または行番号、確認可能な版または日付を記載すること。
4. 未完了事項、疑問点、作業を妨げている原因、ユーザーへの確認が必要な事項。
5. ユーザーが確認した決定と、未確認の提案を明確に区別すること。
6. 次に行う具体的な操作と、実行前に必ず読む資料。

要件：
- 事実、推測、未確認事項を区別し、計画を完了済みとして記載しないでください。
- 結論には適用範囲と制限を示し、一部の確認だけで全件に漏れがないと主張しないでください。
- 既存成果の正確な所在を参照し、重要な判断根拠を残してください。曖昧な要約だけにしないでください。
- 記録の整理のみを行い、新たな調査や業務コードの変更はしないでください。
- プロジェクト既存の引継ぎ保存ルールを優先してください。明確なルールがない場合は、まず回答内にMarkdown本文を出力し、無断でファイルを作成しないでください。

### ② 新会話：読取りと作業継続

以下のタスクを引き継いでください。最初に引継ぎ記録を読んでください。
【引継ぎ記録のパス、またはここに本文を貼り付ける】

以下の順序で実行してください。
1. 引継ぎ記録と、そこで指定された必要資料を読んでください。アクセス不可、欠落、版が不明な内容は明示し、読んだふりをしないでください。
2. タスクの目的、制約、完了事項、未完了事項、次の作業を簡潔に言い直し、矛盾がないか確認してください。
3. 引継ぎ記録は作業の手掛かりとして扱ってください。既存の結論を引用する際は、証拠が結論を支持しているか、版が適用可能かを確認し、重要な結論は原資料に戻って確認してください。
4. 既存の許可範囲内で、次の未完了作業を継続してください。情報が不足する場合は、影響を受ける部分だけを停止し、何を補足する必要があるか説明してください。
5. プロジェクトのルールに従い、進捗、結論、証拠、未処理事項を更新し、後続の会話でも引き継げるようにしてください。

確認済みで証拠が引き続き適用できる作業を重複実行せず、タスクの範囲を拡大せず、無断で業務コードを変更しないでください。各報告では一つの重点だけを説明し、実際に完了したことと残っていることを明示してください。
