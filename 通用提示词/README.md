- AI 智能体与 Manual 的机制调查安排在追加开发之后；公司实际路径、版本与 Thema 应从实际工程核实。
- HTML 下载到电脑后用浏览器打开，可选择中文、日本語或中日对照并复制正文；页面本身不读取或上传公司工程。
- AI 调查提示词以 MD 为维护来源。修改 MD 后，在其目录执行 `python 生成阅读版.py` 更新 HTML；脚本使用 Python 标准库。
