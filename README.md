## 中文：平时怎么用

1. 从总任务 Issue 或「追加开发」开始，先确认实际项目、资料位置和 Source 基准。
2. 在公司实际业务工程中，把需要的任务正文交给 Claude；中日两版选择一种语言，只执行一次。
3. 根据确认后的开发 Input 推进设计、Source 开发、测试和交接；按需使用通用提示词与开发环境模板。

两份编号为 P002 的提示词已按用途分目录：14 项目核对在「追加开发」，AI 智能体与 Manual 调查在「通用提示词」。历史资料用于追溯，原有环境说明或授权不自动作为现用规则。公司业务资料和实际成果保存在公司工程内。

## 日本語：日常の使い方

1. 総合Issueまたは「追加开发」から始め、実案件・資料の場所・Source基準を確認します。
2. 会社の実業務工程で必要なタスク本文をClaudeへ渡します。中日二言語から一方を選び、一度だけ実行します。
3. 確認済みInputから設計・Source開発・試験・引継ぎへ進み、必要に応じて共通プロンプトや開発環境のテンプレートを使います。

既存番号P002の二つのプロンプトは用途別に分けました。14案件の照合は「追加开发」、AIエージェントとManualの調査は「通用提示词」です。履歴資料は追跡用で、過去の環境手順や権限を現用ルールとして自動適用しません。会社資料と実成果は会社工程内へ保存します。
