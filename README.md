# Claude Code 开发环境模板

帮助 Claude 理解需求、核对成果、记录进度。先从本页开始。

## 文件结构

```text
README.md                    ← 使用入口
使用说明/
  首次接入提示词.md           ← 第一次发给公司 Claude
模板/
  CLAUDE.md                  ← 工作总则
  当前任务.md                ← 任务与进度记录模板
.gitignore                   ← 排除本地讨论草稿
```

## 在公司怎么用

1. 通过 Git 获取本仓库。
2. 打开 [首次接入提示词](使用说明/首次接入提示词.md)，填写仓库根目录的绝对路径。
3. 在实际业务工程的 Claude Code 中发送该提示词，根据简短反馈继续。

Claude 会按提示词检查已有规则，再合并适用内容。两份模板供 Claude 参考，通常无需你逐项填写。

## 日常使用

- **提出任务：** 说明目标、资料位置和最在意的结果，让 Claude 整理需求。
- **继续任务：** “读取本工程的规则和当前任务记录，核对实际状态，告诉我做到哪里，然后继续。”
- **反馈调整：** 拍下公司 Claude 的简短反馈发到这里，改进后的文件再通过 Git 带入公司。
