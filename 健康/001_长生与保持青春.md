# 001｜长生与保持青春

| 重点 | 核心理解 | 放进日常 |
|---|---|---|
| ① 长息 | 把「長生きは長息」当作提醒。心急时，舒缓的呼吸有助于放松。[1] | 开会前或下班后，松开肩膀，轻轻吸气，再自然呼出，以舒服为度。 |
| ② 慢跑 | 规律活动身体。运动与骨钙素有关，但“跑步震动骨头就能保持青春”仍缺乏直接的人体证据。[2] | 按当天体力调整，累了就走一段或休息。 |
| ③ 七分饱 | 对体重较轻、又常运动的人，“七分饱”可以理解为吃够、吃得舒服。 | 慢慢吃，还有饥饿感就继续，舒服地饱了就停，无需刻意减掉三成饭量。 |
| ④ 心静自在 | “无事一身轻”也可以是手里有事，心里从容。 | 晚饭后留一段空闲，想散步就散步，想坐一会儿也好。 |
| ⑤ 生活有盼头 | 工作有得心应手的地方，休息时仍对外面的世界感到好奇。 | 坐几站电车，挑一个一直好奇的小地方，随意逛逛。 |
| ⑥ 动静相宜 | 身体在动，心也可以静。身体累了，就安心歇。 | 慢跑途中遇到喜欢的风景，可以停下来看看。运动和赏景，都是这趟出门的乐趣。 |
