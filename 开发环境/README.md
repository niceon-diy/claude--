## 中文：首次使用

1. 在公司电脑获取主仓库，在实际业务工程中打开 Claude Code。
2. 打开首次接入提示词，将「模板资料目录」填写为**本仓库内 `开发环境/` 目录在公司电脑上的绝对路径**；该目录下应能找到 `模板/CLAUDE.md` 和 `模板/当前任务.md`。
3. 将填写后的正文发给 Claude，让它先核实已有工程规则，再按需要合并模板并检查实际结果。

已有规则和任务记录时优先沿用。本目录提供模板；业务 Source、Thema、设计资料与成果位置仍以公司实际工程为准。历史部署记录放在[历史归档](../历史归档/README.md)，不自动成为当前环境的操作步骤或授权。

## 日本語：初めて使うとき

1. 会社のPCで主リポジトリを取得し、実業務工程でClaude Codeを開きます。
2. 初回導入プロンプトのテンプレート保存先には、**会社PC上にある本リポジトリ内の `开发环境/` ディレクトリの絶対パス**を記入します。その直下に `模板/CLAUDE.md` と `模板/当前任务.md` があることを確認してください。
3. 記入した本文をClaudeへ渡し、既存の工程ルールを確認してから、必要なテンプレートを統合し、実際の結果を確認させます。

既存のルール・タスク記録は優先して利用します。本ディレクトリはテンプレートを提供するものであり、業務Source・Thema・設計資料・成果の保存先は実際の会社工程に従います。過去の導入記録は[历史归档](../历史归档/README.md)に保管し、現在環境の手順や権限として自動適用しません。
